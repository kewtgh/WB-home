## 实施原则

1. 保持静态托管与零后端部署方式。
2. 不引入 package manager 或前端框架。
3. 中英文功能、结构和隐私能力同步交付。
4. 所有核心功能在 JavaScript 不可用时仍保留基本内容和联系方式。
5. 先解决隐私、可访问性和回归风险，再增加转化功能和视觉微调。
